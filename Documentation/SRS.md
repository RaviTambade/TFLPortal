# Software Requirements Specification (SRS)

## Project Management System

### Prepared for: Transflower Learning Mentor Perspective

## 1. Introduction
The Project Management System is a web-based application designed to support organizations in managing projects, assigning tasks, tracking employee progress, and maintaining timesheets in a structured digital environment. The system is intended to improve communication between managers and team members while supporting productivity, accountability, and project visibility.

## 2. Purpose of the System
The purpose of this system is to provide a centralized platform where project managers can create and manage tasks, track work progress, review employee timesheets, and monitor project-related activities. Employees can use the system to view assigned tasks, update their status, and record their working hours efficiently.

## 3. Scope of the Project
The system will cover the following major areas:
- User registration and authentication
- Role-based access for managers and employees
- Project and task creation
- Task assignment and status updates
- Timesheet management
- Basic reporting and monitoring of task progress

The system is intended for internal organizational use and focuses on project coordination and workforce tracking.

## 4. Objectives
The key objectives of the system are:
- Improve coordination between managers and employees
- Reduce manual effort in task and timesheet management
- Provide a clear workflow for task completion
- Support better tracking of project progress
- Encourage accountability and transparency in team operations

## 5. Stakeholders and Users
### 5.1 Project Manager / Admin
The manager is responsible for:
- Creating projects and tasks
- Assigning tasks to employees
- Reviewing task progress
- Monitoring timesheets
- Managing team-related information

### 5.2 Employee / Team Member
The employee is responsible for:
- Viewing assigned tasks
- Updating task status
- Recording work hours
- Reviewing personal timesheet information

## 6. Functional Requirements
### FR1: User Registration and Login
The system shall allow new users to register and existing users to log in securely using valid credentials.

### FR2: Role-Based Access Control
The system shall provide separate access for managers and employees based on their roles.

### FR3: Project and Task Management
The system shall allow managers to create, edit, and delete tasks assigned to employees.

### FR4: Task Status Updates
Employees shall be able to update task status such as Not Started, In Progress, or Completed.

### FR5: Timesheet Management
The system shall allow employees to record their working hours and allow managers to review timesheets.

### FR6: Employee Management
The system shall allow authorized managers to add or remove employees from the system as required.

### FR7: Reporting and Monitoring
The system shall provide information related to project progress, employee work updates, and timesheet records.

## 7. User Interfaces
The system shall provide the following user interfaces:
- Login and registration page
- Manager dashboard
- Employee dashboard
- Task management interface
- Timesheet interface
- Task update interface

## 8. Non-Functional Requirements
### 8.1 Security
The system shall ensure that only authorized users can access sensitive data and that employees can view only their own relevant information.

### 8.2 Reliability
The system shall maintain data integrity and support consistent operation during normal use.

### 8.3 Availability
The system shall be accessible during regular business hours and should support continuous operation whenever required.

### 8.4 Maintainability
The system shall be designed using modular components so that future updates and maintenance can be handled efficiently.

### 8.5 Scalability
The system shall support growth in the number of users, projects, and tasks without major structural changes.

### 8.6 Usability
The interface shall be simple, clear, and easy to understand for both managers and employees.

### 8.7 Portability
The system shall be deployable on standard web-based platforms and should be compatible with common operating environments.

## 9. System Behavior
On startup, the user will be presented with options to log in, register, or access the appropriate dashboard based on their role. Managers can create and assign tasks, while employees can update their assigned work and record time spent.

## 10. Assumptions and Constraints
- The system is expected to operate within an organization using standard web technologies.
- A database will be used to store user, task, and timesheet information.
- Internet access is required for accessing the application through the web interface.

## 11. Benefits of the Project
The project helps organizations reduce communication gaps, improve task tracking, simplify timesheet handling, and create a more productive working environment for both managers and employees.

## 12. Transflower Mentor Perspective
From a Transflower mentor perspective, this project is a valuable learning example for understanding how real business requirements are transformed into software solutions. It helps learners connect user roles, business workflows, and technical implementation in a practical and meaningful way.

## 13. Assumptions and Dependencies
- The system is expected to be used by an organization with a defined team structure.
- The application depends on a database for storing users, tasks, projects, and timesheet information.
- The system assumes a stable web environment for deployment and user access.

## 14. Constraints
- The project scope is limited to core task and timesheet management features.
- The initial version may not include advanced analytics or complex workflow automation.
- User interfaces are expected to be simple and role-oriented rather than highly customized.

## 15. Use Cases
- Manager logs in and creates a task for an employee.
- Employee logs in and updates the status of the assigned task.
- Manager views employee timesheets and project progress.
- Employee submits working hours for review and payroll support.

## 16. Glossary
- Project Manager: The user who supervises tasks and team activities.
- Employee: The user who performs assigned tasks and updates their work status.
- Timesheet: A record of hours worked by an employee.
- Task Status: The progress state of a task such as Not Started, In Progress, or Completed.

## 17. Conclusion
The Project Management System provides a professional and practical approach to managing team-based work. It supports core business processes such as task assignment, work tracking, and time management, making it a useful solution for modern organizations.
